# Genies

> Genies is an AI avatar and digital-identity company powering the visual and embodiment layer for AI. Its Unity-based Avatar SDK lets developers integrate high-fidelity, fully customizable 3D avatars and "Smart Avatars" (LLM- and behavior-driven characters) into games, apps, and XR experiences across iOS, Android, Windows, and VR. Developers register a project in the Genies Developer Hub to obtain API keys used by the SDK.

## Developer
- [Developer Documentation](https://docs.genies.com/docs/intro/): Genies technical docs home
- [Getting Started](https://docs.genies.com/docs/sdk-avatar/getting-started/): prerequisites, install (Bootstrap Wizard), and project registration for API keys
- [Avatar SDK Reference](https://docs.genies.com/docs/sdk-avatar/): SDK class/method reference, load-avatar, customization, and asset pre-caching APIs
- [Developer Hub](https://hub.genies.com/): create an account, register a project, and manage API keys
- [Unity Asset Store](https://assetstore.unity.com/genies): download the Genies Avatar SDK
